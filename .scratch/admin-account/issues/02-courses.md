# 02: Курсы и категории

**What to build:** Администратор просматривает и фильтрует курсы, создаёт курс и проходит полноценные формы управления курсами и категориями.

**Blocked by:** 01 — Вход и мобильный кабинет администратора.

**Status:** ready-for-agent

- [ ] Доступны список курсов, категории, число/список связанных групп, поиск и фильтры с реальными чтениями API.
- [ ] Создание курса передаёт поддерживаемые поля API и обновляет связанные списки после подтверждённого успеха.
- [ ] Переименование, смена категории и удаление имеют формы, валидацию, подтверждение удаления и дальнейший флоу. При отсутствии endpoint вызов мутации пропущен; результат не выдаётся за серверное изменение.
- [ ] Управление категориями имеет полноценный UI без отсутствующих мутаций. Новые локальные значения не отправляются вместо фиксированного API enum; параллельная система меток не создаётся.
- [ ] Перед подключением проверен актуальный контракт: новые доступные операции выполняются реально, отсутствующие URL не придумываются.
- [ ] Соблюдены мобильный взрослый украинский UI, состояния загрузки/пустого списка/ошибки, обработка 401/403 и запрет повторного submit. Выполнен `bun check`; `.test` файлы не создаются.
