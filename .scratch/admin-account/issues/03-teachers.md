# 03: Преподаватели — список, профиль и регистрация

**What to build:** Администратор находит преподавателя, открывает его профиль с группами и регистрирует нового преподавателя с получением кода доступа.

**Blocked by:** 01 — Вход и мобильный кабинет администратора.

**Status:** resolved

- [ ] Список использует пользователей с ролью teacher, поддерживает поиск и переход в профиль; профиль показывает реальные группы.
- [ ] При интеграции проверено различие ID аккаунта и профиля. Идентификаторы не подменяются предположениями и вопрос не перекладывается на пользователя.
- [ ] Регистрация по имени использует доступный API, валидирует ввод, предотвращает повторный submit и обновляет список после успеха.
- [ ] Экран результата показывает выданный код и копирование; код не сохраняется в URL, localStorage, журнале или дополнительной БД.
- [ ] Если профиль не удаётся загрузить из-за ограничений контракта/прав, отображается реальная ошибка, а не выдуманные данные.
- [ ] Соблюдены мобильный взрослый украинский UI и состояния загрузки/пустого списка/ошибки, обработаны 401/403. Выполнен `bun check`; `.test` файлы не создаются.

## Результат интеграции

Принято по ревью diff: `7aa2c41` и `0b5df4b` в integration (исходные `0395146b9e5d47f2dd3f8885cba903b73ffda99c`, `7acd37b15c8846ee2ba1b0ca380e4227a2561f02`). Повторный `bun check` прошёл; объединённые routes/locales регенерированы, сборка прошла. Подключён вход со страницы людей, реальные чтения пользователей/профиля/групп и регистрация с кодом в памяти.

Идентификаторы: список и ссылки регистрации используют account `user_id`; ответ профиля проверяется на совпадение `profile.user_id` и роль teacher, несовпадение не показывает чужой профиль. Живой OpenAPI не уточняет семантику teacher_id; без authenticated-сессии нельзя подтвердить, принимает ли endpoint account ID. Этот технический предел явно сохранён: при несовпадении или недоступности показывается ошибка, а не выдуманные группы. Реальная регистрация, authenticated ID mapping, 403 и мобильный браузер end-to-end не проверены. Исходный чек-лист не является протоколом таких проверок.
