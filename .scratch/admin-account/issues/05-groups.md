# 05: Группы — создание и управление

**What to build:** Администратор находит группу, смотрит её детали, создаёт группу с выбором существующего курса и проходит UI изменения или удаления группы.

**Blocked by:** 01 — Вход и мобильный кабинет администратора.

**Status:** ready-for-agent

- [ ] Каталог использует общие курсы/группы API, не ограниченный текущим преподавателем список. Есть поиск, фильтры курса/категории/преподавателя и реальные детали группы.
- [ ] Создание с названием и курсом выполняется через API и обновляет связанные списки. Курсы выбираются напрямую из API, поэтому тикет не зависит от интерфейса управления курсами.
- [ ] Допустимость группы без преподавателя следует актуальному контракту; запрет backend показывается как ошибка, не обходится выдуманным назначением.
- [ ] Переименование, смена курса и удаление имеют полный UI-флоу с валидацией/подтверждением. Без endpoints мутации пропущены, серверные данные не подменяются; доступные новые endpoints подключаются реально.
- [ ] Детали содержат доступные данные преподавателей и учеников; точки входа в управление составом подключаются последующими тикетами без неработающих переходов.
- [ ] Соблюдены мобильный взрослый украинский UI, загрузка/пустые состояния/ошибки, 401/403 и защита submit. Выполнен `bun check`; `.test` файлы не создаются.
