# 13: Каталог наград и изображения

**What to build:** Администратор просматривает, фильтрует и создаёт награды, проходит управление позициями и выбирает изображение ссылкой либо файлом с телефона.

**Blocked by:** 01 — Вход и мобильный кабинет администратора.

**Status:** resolved

- [ ] Список, детали и фильтры используют API. Создание отправляет поддерживаемые название, цену, описание, тип reward/privilege и категорию либо отсутствие привязки.
- [ ] Перед реализацией проверен актуальный контракт. Доступные операции выполняются реально; редактирование, скрытие/доступность и удаление без endpoints остаются полноценными UI-флоу без серверной мутации и подмены кэша.
- [ ] В форме доступны режимы «Посилання» и «Вибрати файл», локальный предпросмотр, замена и удаление выбора. Обработаны некорректная ссылка/неподходящий файл; временные ресурсы предпросмотра освобождаются.
- [ ] Без storage/поля изображения выбор остаётся локальным и не выдаётся за загруженный файл. Поддерживаемые поля самой награды всё равно создаются реально, а UI различает сохранённую позицию и несохранённое изображение.
- [ ] Не придумываются endpoint загрузки, таблицы каталога, постоянное хранение файла в localStorage или обход отсутствующего API через PostgreSQL. Ученический магазин ради этого тикета не переделывается.
- [ ] Нет выдачи, очереди выдачи, склада, покупки, возвратов, использования/сроков выданных привилегий. Окончательные правила наград не придумываются.
- [ ] Соблюдены мобильный взрослый украинский UI, загрузка/пустые состояния/ошибки, 401/403 и защита submit. Выполнен `bun check`; `.test` файлы не создаются.

## Результат интеграции

Принято по ревью и интегрировано: `61e8d2c`, `1a75baf` (исходные `dbc97922af74d345cd46a8dd0b46f10889eb2142`, `5dced628cc608e261308bc22e443c4c336150569`). Объединённые routes/locales регенерированы, сборка прошла, повторный `bun check` в integration прошёл с прежними шестью предупреждениями React.

Реальные список/детали/создание подключены по актуальному OpenAPI. Изменение/удаление/показ/скрытие — подтверждаемые локальные результаты без фиктивной мутации или подмены кэша. Ссылка и файл изображения поддерживают предпросмотр, замену, удаление и освобождение object URL; сохранение награды отделено от несохранённого изображения. На ревью добавлены runtime-переводы, сброс состояния при смене rewardId и полный UI доступности без выдуманного текущего hidden-статуса.

Ограничения: authenticated-операции, мобильный браузер и соответствие backend-фильтра «no category» значению null при создании не проверялись end-to-end. Чек-лист выше — исходные требования, не протокол браузерных проверок. Никаких storage/таблиц/выдачи/покупок не добавлено.
