# 06: Назначение преподавателей на группы

**What to build:** Администратор меняет преподавателей конкретной группы и массово назначает преподавателей нескольким группам с понятным результатом каждой операции.

**Blocked by:** 05 — Группы — создание и управление.

**Status:** ready-for-agent

- [ ] Выбор преподавателей использует реальный список teacher из API и работает без завершения тикета регистрации преподавателей.
- [ ] Можно назначить до двух преподавателей, заменить состав и снять назначения через доступную мутацию. Передаются user IDs, не ID профилей.
- [ ] Пустой список разрешается интерфейсом, если контракт не требует минимум; серверный запрет отображается корректно.
- [ ] Выбор доступен из деталей/создания группы; после сохранения обновляются детали и затронутые списки. Из преподавательского профиля действие подключается, когда этот профиль реализован.
- [ ] Массовое назначение показывает результат по каждой группе и позволяет повторить однозначно неуспешные записи, не заявляя общей транзакции.
- [ ] Соблюдены мобильный взрослый украинский UI, состояния запросов и 401/403. Выполнен `bun check`; `.test` файлы не создаются.
