# 01: Вход и мобильный кабинет администратора

**What to build:** Администратор входит существующим фиксированным паролем, попадает в мобильный кабинет со списком групп, использует навигацию, настройки и выход. Связано с #41; родительскую задачу не закрывать.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Общий вход, восстановление сессии и домашний маршрут корректно поддерживают admin. Пароль не попадает в клиентский код; создание admin и смена пароля отсутствуют.
- [ ] Guards и redirects не создают циклов; чужие роли не получают доступ к кабинету. Ученические и преподавательские переходы сохраняют поведение.
- [ ] Мобильная навигация ведёт к обучению, людям, каталогу и настройкам; ещё не реализованные разделы не вызывают падений и подключаются последующими тикетами. Стартовый экран показывает реальные группы с состояниями загрузки, ошибки и отсутствия данных.
- [ ] Настройки показывают имя/роль, управление анимациями и выход. Ученические credentials для admin и teacher не запрашиваются; выход очищает клиентские данные сессии.
- [ ] Исправлены существующие ошибки типов роли admin в навигации и переходе после входа.
- [ ] Интерфейс только для телефона, взрослый и украинский, без uppercase и более трёх крупных карточек на странице.
- [ ] Проверены 401/403, обновление страницы, прямые переходы и существующие роли. Выполнен `bun check`; `.test` файлы не создаются.
