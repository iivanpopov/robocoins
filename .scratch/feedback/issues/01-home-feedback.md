# 01: Обратная связь с главной ученика

**What to build:** Ученик отправляет идею, проблему или другое сообщение с главной и получает подтверждение сохранения в Neon. Один общий модуль обслуживает все последующие точки входа.

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [ ] После истории доступна текстовая кнопка и форма с типом и сообщением.
- [ ] Drizzle-схема и миграция создают одну таблицу feedback: UUID, серверное время, kind, source, message, nullable student_id и student_name.
- [ ] Общая TanStack Start POST server function валидирует данные Valibot и сохраняет через существующее подключение Neon.
- [ ] Автор определяется серверной сессией; авторизованные сценарии требуют ученика.
- [ ] Сообщение обрезается по краям и ограничено 3–2000 символами; допустимые типы и источники ограничены в БД и вводе.
- [ ] Подготовлены единые режимы home, registration avatar, profile avatar и shop без дублирования компонентов и server functions.
- [ ] UUID обеспечивает безопасный повтор без дубликатов, с проверкой совпадения обращения и автора.
- [ ] Ошибка сохраняет текст, повтор доступен; успешная отправка подтверждается без обещания ответа.
- [ ] Проверены сохранение, ошибки, повтор и bun check; .test-файлы не создаются.
