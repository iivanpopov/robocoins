# 04: Предложение аватара после регистрации

**What to build:** Ученик предлагает новый аватар из собственного профиля. Самостоятельная смена аватара сейчас отсутствует и не входит в этот тикет.

**Blocked by:** 01 — Обратная связь с главной ученика.

**Status:** ready-for-human

- [ ] Кнопка предложения доступна в собственном профиле ученика, но не при просмотре чужого профиля и не в интерфейсе преподавателя.
- [ ] Используется общий модуль из 01, без своей формы, схемы или server function.
- [ ] Обращение сохраняется с avatar_suggestion, profile_avatar и подтверждённым автором.
- [ ] Отправка не изменяет текущий аватар; новая возможность смены аватара не добавляется.
- [ ] Проверены пользовательский сценарий и bun check; .test-файлы не создаются.
