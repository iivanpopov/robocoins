Зафиксирован выбранный стиль: минималистичная нижняя навигация для мобильного экрана.

- Навбар горизонтальный, на всю ширину экрана и закреплён к нижнему краю.
- Фон — поверхность приложения (`--surface`), Без цветной плашки и тяжёлой тени.
- Два пункта размещены равномерно, каждый занимает половину доступной ширины.
- Пункт состоит из иконки над короткой подписью; иконки — Phosphor через UnoCSS.
- Первый пункт — настройки. Для студента: «Настройки», для преподавателя тоже.
- Второй пункт — «Профиль» для студента или «Дашборд» для преподавателя.
- Активный пункт выделяется цветом бренда (`--brand`); неактивный — приглушённым цветом (`--muted-foreground`).
- Учесть безопасную область устройства снизу через `env(safe-area-inset-bottom)`.
- Стиль использует палитру и скругления проекта, без самостоятельных декоративных цветов.
